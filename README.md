# Voilo

**A modern music player for iOS with a Material You-inspired design.**

Voilo is a customizable music player for iOS, featuring a modern interface, local music library, online music sources, playlists, and various playback options.

 Features

 🎵 Music Player
- Play and pause music
- Previous and next track controls
- Shuffle and repeat modes
- Track progress and seeking
- Favorite tracks
- Playback queue
- Mini player available throughout the app

 📚 Music Library
- Browse your music collection
- View recently added tracks
- Search for songs
- Organize and manage music
- Import audio files from your device
- Add music using links
- Support for local music files

 🌐 Online Music
- Search for music online
- Add tracks using YouTube links
- View available track information and artwork
- YouTube video integration
- Embedded YouTube playback
- Online music discovery

 📋 Playlists
- Create custom playlists
- Add and manage tracks
- Organize your music collections
- View playlist contents
- Manage empty and existing playlists

 🎨 Customization
- Material You-inspired design
- Multiple color themes and palettes
- Custom accent colors
- Light mode
- Dark mode
- System appearance
- AMOLED black mode
- Dynamic interface colors

 ⚙️ Settings
- Appearance customization
- Playback preferences
- Music source selection
- On-device music
- Apple Music source option
- Online source preferences
- Sleep timer with multiple time intervals

 🔎 Search
- Search for music
- Online search
- Search history
- Quick access to previous searches

 Interface

Voilo features a clean mobile interface inspired by Google's Material You design language, adapted for iOS.

The application includes:
- Home screen
- Music library
- Online music section
- Playlists
- Settings
- Full-screen player
- Persistent mini player

 Development

Voilo is an actively developed project. New features, improvements, and design updates are planned.

The current version is a work in progress, and functionality may change as development continues.
